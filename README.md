# Лабораторная работа №1 — Линейная регрессия и факторный анализ

## Описание проекта
Файл lab1.ipynb в папке data!!!

Лабораторная работа посвящена прогнозированию прочности бетона на сжатие с использованием методов машинного обучения и анализа главных компонент.

Для исследования используется набор данных Concrete Compressive Strength, содержащий 1030 наблюдений и 8 независимых числовых признаков.

## Используемые методы

- Linear Regression
- Ridge Regression
- Lasso Regression
- Корреляционный анализ и VIF
- Кросс-валидация
- Метод главных компонент (PCA)
- Анализ остатков и тест Бройша — Пагана

## Результаты

До применения PCA модели показали RMSE около 9,796 МПа и R² около 0,628.

После применения PCA размерность данных сокращена с 8 до 6 признаков с сохранением 97,31% объяснённой дисперсии.

При этом RMSE увеличилась примерно до 10,552 МПа, а R² снизился до 0,568.

Таким образом, PCA позволил уменьшить размерность признакового пространства, но не улучшил точность прогнозирования.

## Структура проекта

- `lab1.ipynb` — основной Jupyter Notebook с кодом, графиками и выводами.
- `appendix_code.py` — полный листинг программного кода.
- `data/concrete_data.csv` — используемый датасет (если разрешено его распространение).
- `requirements.txt` — необходимые Python-библиотеки.

## Запуск проекта

1. Установить Python и необходимые библиотеки командой `python -m pip install -r requirements.txt`.
2. Скачать датасет Concrete Compressive Strength с Kaggle, если CSV не включён в репозиторий.
3. Поместить файл `concrete_data.csv` в папку `data`.
4. Открыть `lab1.ipynb` в VS Code с расширениями Python и Jupyter.
5. Выбрать Python Kernel и выполнить все ячейки последовательно.
